# OFFLINE JAVA SHUTER

## Цель создания
Это простенькая 2D игра написанная исключительно на java.
Сделана по ходу изучения ООП для улучшения понимания правил архитектуры

## Игровые механики
В игре тебе нужно собирать монеты и убивать врагов которых с каждой волной все больше.
После убийства всех врагов появляется новая волна врагов в которой на 1 врага больше чем в прошлой волне.
За сбор монет и убийство врагов тебе начисляются очки.

У игрока есть 2 типа оружия , меч и пули.
Меч и пуля появляются в том направлении в котором вы последний раз передвигались.
И у меча и у пули есть свой кд.
При использовании меча на короткое время появляется статическая область в которой все враги  получают урон.
При использовании пули появляется пуля которая летит в одном напрвалении.
При столкновении пули и врага пуля исчезает а враг получает урон.

При столкновении врага с игроком враг погибает а игрок теряет часть здоровья.
Как только здоровье игрока опускается до 0 появляется кнопка рестарта и все игровые процессы останавливаются.
После нажатия кнопки restart все сбрасывается до изначальных показателей , очки , враги , волны .Игра начинается заново.

После смерти игра попросит ввести имя под которым она сохранит ваш счет очков за игру. Игра будет сохранять вас после каждой смерти, сохраненные данный отправляются
в базу данных которая хранит полученных игроков не зависимо от того, работает сейчас приложение или нет. Также после смерти вам будет показана таблица игроков набравших наибольшее количество очков за все время. Если вы набрали меньше 300 очков то игра не будет вас записывать. Если при вводе имени вы нечего не ввели или ввели только пробелы, игра запишет ваши результаты под именем NAME

## Клавиатура
|Клавиша|Действие|
|---|---|
|W,A,S,D|перемещение игрока|
|Space|атака|
|Shift|смена оружия|
|Backspce|Debug:мгновенное убийство игрока|
|Ctrl|открывает таблицу лучших игроков

## Как запустить игру
Скопируйте репозиторий ,откройте в любой IDE поддерживающий язык java ,найдите файл main.java и запустите его

предварительно нужно запустить Spting-Boot  сервер

## Архитектура
`PlayerApiClient` - место откуда отправляются запросы на сервер(сохранение игрока в базу и получение лучших игроков из базы)

`GameObject` - абстрактный класс ,то что должно быть у каждой сущности и объекта

`Player,Enemy,Coin,Mech,Pulya` - игровые объекты и сущности

`PlayerScore` - нужен для передачи данных на сервер

`Direction,Weapon` - enum классы

`Main` - запускает всю игру и создает окно

`GamePanel` - центральный класс ,отвечает за игровой цикл ,отрисовку всех объектов ,ввод с клавиатуры
и логику удаления ,появления .Дает указания другим классам(движение, получение урона, появление)
